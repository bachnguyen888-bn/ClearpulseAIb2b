# ClearPulse — rules for anything written about this business

- The business name is **ClearPulse**. Use the full name wherever space allows.
- **Never abbreviate it as "CP"**, in any file, copy, commit message, comment or chat reply. Those initials carry a harmful unrelated connotation.
- If a short form is genuinely needed (e.g. the favicon), use **"CPLS"** — it comes from `brandShortName` in `site.config.mjs`.
- `npm run build` fails if "CP" appears in the built pages or favicon.
